## GitHubの使い方
</summary>
- 各自がrenewal/2026shingetsusaiブランチから自分用ブランチを作成して作業する。  
- ブランチ名は[feature/自分の名前(アルファベット)]とする(自分の名前はお互いに識別可能なら本名でなくて良い)  
- 親ブランチ(renewal/...)へのマージはプルリクエストを介してのみ行い、金栄によるレビューを必須とします。  
- 親ブランチに残っている一昨年の分のファイルとかは削除してもらって大丈夫です(他のブランチにアーカイブがあるため)  
- 不明点があれば遠慮なく金栄に聞いてください。
