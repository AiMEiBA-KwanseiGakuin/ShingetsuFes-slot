# Slot_2026.pyの使い方
Pythonのバージョンは3.11くらい  
外部ライブラリとしてpygame, pyserialが必要なので、コンソールとかターミナルとかで`pip install pygame pyserial`を実行してインストールしてください。  
タブレットとPCの接続はUSBケーブルとSpaceDesk(アプリ)を使うので、タブレットとPCにそれぞれアプリを入れておいてください。  
Slot_2026.pyの13行目にある`USE_SERIAL=True`をFalseにすると、シリアル通信を使わずにPCのキーボードで操作できるようになります。(Trueにしててもキーボード操作はできます)  
キーは、qで左、wで真ん中、eで右、enterでスタート、spaceで全停止(タイムアップ用)です。  

Arduinoからのシリアル通信はレバー:"S", 左ボタン:"L", 中ボタン:"M", 右ボタン:"R", タイムアップ(あれば)"T"です。
