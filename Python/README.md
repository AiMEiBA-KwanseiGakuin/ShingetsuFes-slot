# Pythonにおけるクラスの基本

## クラスって？
ざっくりいうと関数と変数をまとめたもの  

### クラスの定義
```python
class クラス名:
    def __init__(self, 引数1, 引数2):
        self.変数1 = 引数1
        self.変数2 = 引数2

    def メソッド名(self, 引数):
        処理
```
__init__はコンストラクタと呼ばれ、クラスのインスタンス化の際に呼び出される特殊なメソッドです。  

### クラスのインスタンス化
```python
インスタンス名 = クラス名(引数1, 引数2)
```

### 使い方
self.がついた変数は、クラス内の関数からはself.変数名でアクセスでき、クラス外からはインスタンス名.変数名でアクセスできます。
